# Главная страница TIBON

`frontend/app/routes/home.tsx` собирает девять секций. За первым экраном идут направления, блок о студии, поводы собраться, встроенная фотоподборка, впечатления, подборка форматов, дополнительные услуги и заявка. Секции находятся в `components/home/` и используют общие компоненты проекта.

Данные карточек и галереи находятся в `frontend/app/data/home.ts`. Компоненты используют типизированные поля изображения, текста и маршрута. При интеграции CMS их можно передавать из серверного loader. Подборка форматов редакционная, без цен и заявлений о популярности. CTA ведут на форму `/zayavka/`.

Главная отдаёт title, description и Open Graph в SSR-разметке. После подтверждения домена задайте `PUBLIC_SITE_ORIGIN` на сервере для вывода canonical, `og:url` и абсолютного `og:image` с портретом основателя.

## Композиция главной

Первый экран построен на чёрном поле с крупным заголовком «Кулинарная студия Рената Исмагилова». На широких экранах портрет стоит справа и доходит до нижнего края секции, на телефоне — между заголовком и описанием. Снимок приготовления сопровождает описание. Два направления имеют разные пропорции кадров, поводы собраться используют светлый фотоиндекс, финальная секция — фирменный красный.

Логотип в шапке, мобильном меню и футере использует подготовленный из файла заказчика `logo1.png`. Исходный логотип с белой надписью сохранён в оформлении, для веб-версии обрезаны прозрачные поля. Вступление первого экрана учитывает уменьшенное движение. Встроенная фотоподборка сохраняет управление лайтбоксом с клавиатуры.

## Проверка

Из `frontend/` запустите `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` и `npm run test:ssr`. Последняя команда проверяет на production-сборке SSR, ссылки, изображения, галерею с клавиатуры и мобильную навигацию в Chromium.

В M4.1 композиция проверена в Chromium на ширинах 360, 390, 768, 1024, 1440 и 1920 px. На этих ширинах измеренный контраст надписей первого экрана на фоне градиента и кадра составил не менее 5.24:1. Скриншоты главной сохранены в `frontend/test-results/m4.1/home-390.png` и `frontend/test-results/m4.1/home-1440.png`.

Четыре ключевых страницы редакции «Кухня крупным планом» просмотрены в Playwright MCP на 390, 768, 1280 и 1920 px.
