# Главная страница TIBON

`frontend/app/routes/home.tsx` собирает девять секций. За первым экраном идут блок о студии, направления, поводы собраться, впечатления, встроенная фотоподборка, дополнительные услуги, подборка форматов и заявка. Секции находятся в `components/home/` и используют общие компоненты проекта.

Данные карточек и галереи находятся в `frontend/app/data/home.ts`. Компоненты используют типизированные поля изображения, текста и маршрута. При интеграции CMS их можно передавать из серверного loader. Подборка форматов редакционная, без цен и заявлений о популярности. CTA ведут на форму `/zayavka/`.

Главная отдаёт title, description и Open Graph в SSR-разметке. После подтверждения домена задайте `PUBLIC_SITE_ORIGIN` на сервере для вывода canonical, `og:url` и абсолютного `og:image` с портретом основателя.

## Композиция главной

Первый экран использует оригинальный портрет Рената и тёмный гастрономический фон по мотивам предоставленного PDF «на главную 2.pdf». На широком экране портрет расположен слева, текст и действия в центре, а справа виден крупный план блюда. На телефоне портрет и блюдо образуют общий кадр над заголовком и кнопками. Два направления различаются пропорциями и положением кадров, события собраны в тёмную трёхколоночную композицию, финальная заявка размещена на чёрном фоне.

Логотип в шапке, мобильном меню и футере использует подготовленный из файла заказчика `logo1.png`. Исходный логотип с белой надписью сохранён в оформлении, для веб-версии обрезаны прозрачные поля. Встроенная фотоподборка сохраняет управление лайтбоксом с клавиатуры.

На первом экране описание и действия мягко появляются через CSS. Заголовок блока о студии, его фото, заголовок фотоподборки и фото партнёра получают одноразовое лёгкое движение при попадании в область просмотра. Селекторы `data-editorial-reveal` наблюдаются внутри текущей страницы и очищаются при уходе со страницы. CSS и Web Animations API учитывают `prefers-reduced-motion`, исходная HTML-разметка показывает контент при отключённом JS.

## Изображения

Фон первого экрана создан встроенным ImageGen по мотивам предоставленного PDF. Сюжет — стейк, зелень и специи на чёрном сланце. Главная предзагружает вариант `frontend/public/images/studio/home-hero-slate.webp` (1536 × 1024 px) или `home-hero-slate-mobile.webp` (840 × 560 px). Портрет из предоставленного `Renat.jpg` загружается отдельным изображением и используется для Open Graph.

Блок дополнительных услуг и первый экран `/dop-uslugi/` используют WebP-копии предоставленного снимка `druzya.jpg` шириной 480 и 1086 px. Портрет ведущего на странице услуг взят из предоставленного файла `podkin.jpg`.

Файлы в `frontend/public/images/home/` — временные иллюстрации с [Unsplash License](https://unsplash.com/license). Интерьер и кадры фотоподборки показаны как иллюстрации. Страница меню также использует `shared-table.webp` как иллюстрацию сервировки.

## Проверка

Из `frontend/` запустите `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` и `npm run test:ssr`. Последняя команда проверяет на production-сборке SSR, ссылки, изображения, галерею с клавиатуры и мобильную навигацию в Chromium.

В M4.1 композиция проверена в Chromium на ширинах 360, 390, 768, 1024, 1440 и 1920 px. На этих ширинах измеренный контраст надписей первого экрана на фоне градиента и кадра составил не менее 5.24:1. Скриншоты главной сохранены в `frontend/test-results/m4.1/home-390.png` и `frontend/test-results/m4.1/home-1440.png`.

Скриншоты редакции Dark Editorial Gastronomy сохранены в `frontend/test-results/creative-redesign/`.
