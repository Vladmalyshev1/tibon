# Главная страница TIBON

**M4.2 — Dark Cinematic Visual Alignment · In progress.** Утверждённое направление — **Dark Cinematic Gastronomy**. Текущий этап ограничен документацией. Раздел «Исходная реализация» описывает состояние кода перед M4.2.

## Цель M4.2

- [site-concept.png](references/site-concept.png) задаёт целевые композиции секций, ритм тёмных поверхностей и крупной гастрономической фотографии. [chef-hero-reference.png](references/chef-hero-reference.png) имеет приоритет для первого экрана. На десктопе портрет шефа слева, крупный serif-заголовок и действия справа, блюдо крупным планом в нижней правой части. Направленный тёплый свет подчёркивает шефа и блюдо на тёмном фоне.
- На телефоне сохраняются тёмная основа, портрет, блюдо, читаемый заголовок и доступные CTA. Кадрирование и порядок блоков подстраиваются под ширину. Автоматический возврат к светлому Premium Editorial запрещён.
- Действующие архитектура, API, backend, формы, маршруты, SEO и функциональные контракты сохраняются. Изображённые в макетах элементы относятся к визуальной композиции.

## Приёмка M4.2

После реализации по отдельному заданию снять минимум desktop 1440 px и mobile 390 px. Для каждого размера сохранить скриншот первого экрана и полной главной. Hero сравнить с `chef-hero-reference.png`, композицию секций и ритм полной страницы — с `site-concept.png`. На телефоне эти же десктопные референсы служат основой для проверки адаптации. Отметить кадрирование портрета и блюда, переносы заголовка, читаемость CTA и сходство палитры и света. Зафиксировать ширины, пути к снимкам и обоснованные отклонения в отчёте M4.2. Дополнительно проверить ширины 320, 768 и 1024 px, клавиатуру, контраст, reduced motion, SSR и SEO.

## Исходная реализация

`frontend/app/routes/home.tsx` собирает шесть секций. За первым экраном идут направления, рассказ о студии и шефе, варианты меню и программы, фотогалерея и приглашение оставить заявку. Секции находятся в `components/home/` и используют общие компоненты проекта.

Данные направлений и галереи находятся в `frontend/app/data/home.ts`. Ссылки пяти основных направлений берутся из существующих данных услуг. С первого экрана можно перейти к направлениям по `#directions` или открыть форму `/zayavka/`.

Главная отдаёт title, description и Open Graph в SSR-разметке. После подтверждения домена задайте `PUBLIC_SITE_ORIGIN` на сервере для вывода canonical, `og:url` и абсолютного `og:image` с портретом основателя.

### Композиция предыдущей версии

Кремовый первый экран сочетает двухстрочный заголовок «Готовим впечатления» и крупный план приготовления. На телефоне фото стоит между заголовком и описанием, а кнопки занимают всю ширину на компактных экранах. На тёмном развороте взрослый и детский мастер-классы используют фотографии разных пропорций, события и аренда представлены ссылками в строках. За портретом основателя и блоком выбора программы следует мозаика из шести кадров. Финальная секция сочетает бордовый фон, фото блюда, заявку и телефон.

Шапка и мобильное меню используют тёмный вариант логотипа `logo.png`, футер — белый `logo1.png`. Галерея сохраняет порядок чтения и навигации в обеих сетках. Enter открывает кадр, стрелки переключают фотографии, Esc закрывает лайтбокс и возвращает фокус.

Вступление первого экрана реализовано через CSS. Intersection Observer передаёт Framer Motion однократные появления при прокрутке. Значение `data-editorial-reveal` задаёт задержку для элемента списка в миллисекундах. Движение учитывает `prefers-reduced-motion`, весь контент доступен в SSR-разметке без JavaScript.

### Проверки исходной версии

Из `frontend/` запустите `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` и `npm run test:ssr`. Последняя команда проверяет на production-сборке SSR, ссылки, изображения, галерею с клавиатуры и мобильную навигацию в Chromium.

Скриншоты Chromium на контрольных ширинах 320, 390, 768, 1024, 1440 и 1920 px сохранены в `frontend/test-results/redesign-2.0/`.
