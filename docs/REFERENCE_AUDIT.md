# REFERENCE AUDIT — ti-bon.ru

Аудит референса для проекта TIBON. Дата: 2026-11-20. Автор: UI/UX Designer.

## 1. Общая информация о референсе

| Параметр | Значение |
| --- | --- |
| Сайт | https://ti-bon.ru/ |
| Тематика | Кулинарная студия: мастер-классы для взрослых и детей, аренда студии, доп. услуги |
| CMS / стек | WordPress + тема Astra + page builder Elementor, SEO-плагин Rank Math |
| Язык | только русский (`lang="ru-RU"`), мультиязычности нет |
| Объём | 14 страниц в `page-sitemap.xml` (отдельного `post`-sitemap нет) |
| Навигация | 6 пунктов верхнего уровня (5 ссылок + выпадающее «О нас»: Контакты, Правила студии); соцсети Instagram, VK, Telegram, MAX; телефон в шапке |
| Футер | логотип, телефон, реквизиты ИП + ОГРНИП, кнопка «Прокрутить вверх» |
| Формы | только «обратный звонок» (имя + телефон) и гейт на странице меню (имя + телефон) |

**Метод и ограничения.**
Источники: HTML главной, markdown всех страниц, `sitemap.xml` / `page-sitemap.xml`, WordPress REST API (`/wp-json/wp/v2/pages`) для проверки пустых страниц и разметки.
Ограничения, которые важно учитывать при чтении документа:

- Браузера нет: реальный рендеринг, hover/focus-состояния, анимации, поведение слайдеров, лайтбоксов и мобильной вёрстки **визуально не проверялись**.
- Мобильная версия оценена только по CSS-медиазапросам и разметке (брейкпоинты 921px и 544px, drawer-меню). Отдельный запрос с мобильным User-Agent выполнить не удалось — инструмент не поддерживает подмену заголовков. Выводы о мобильной версии в §7 — предположения на основе CSS, а не наблюдения.
- PDF-меню (взрослое и детское) не открывались: содержимое, цены и состав блюд **не верифицированы**.
- Тексты первого экрана главной находятся внутри растрового изображения (JPG), в DOM текста нет — точное содержание постера не прочитано.
- Все цены, часы, адрес и телефон ниже — **наблюдения на дату аудита**, а не согласованные данные для нового сайта.

## 3. Анализ каждой страницы

Формат: назначение → секции по порядку → контент → CTA → формы → изображения → замечания.

### 3.1 Главная — `/`

- **Назначение:** точка входа, бренд-презентация.
- **Секции:** 1) полноширинный постер; 2) блок «ЗАКАЗАТЬ ОБРАТНЫЙ ЗВОНОК»; 3) футер.
- **Контент:** весь первый экран — одно растровое изображение 2560×1461 (JPG, имя файла `на-главную-2_page-0001`), текстовый слой отсутствует в HTML. Подзаголовок формы: «Позвоним Вам в рабочее время с 10:00 до 23:00».
- **CTA:** «Перезвоните мне» (кнопка формы). Кнопок перехода к услугам нет.
- **Формы:** обратный звонок — Имя\*, Номер телефона\* (префикс «+7», маска `(912) 345-67-89`), кнопка «Перезвоните мне»; успех — «Спасибо! Мы скоро вам перезвоним.»; ошибки — `alert()`.
- **Изображения:** один промо-постер (вертикальная/горизонтальная композиция с логотипом и текстом внутри картинки).
- **Замечания:** нет H1 (первый заголовок в DOM — H2 «ЗАКАЗАТЬ ОБРАТНЫЙ ЗВОНОК»); нет оффера, цен, форматов, галереи, меню-тизера, соцдоказательств; главная не выполняет роль навигационного хаба. Форма без чекбокса согласия на обработку персональных данных. Текст внутри картинки не индексируется и не масштабируется как текст.

### 3.2 Для взрослых — `/dlya-vzroslyh/`

- **Назначение:** продажа взрослых форматов (праздники, корпоративы, свидания).
- **Секции:** 1) H1 «Кулинарные мастер-классы» + CTA; 2) «МЕРОПРИЯТИЯ ДЛЯ ВЗРОСЛЫХ» (текст + фото); 3) «РОМАНТИЧЕСКОЕ СВИДАНИЕ ДЛЯ ДВОИХ» (текст + фото); 4) блок обратного звонка.
- **Контент (наблюдение):** поводы — день рождения, корпоратив, девичник, мальчишник, «просто праздник»; формат — мастер-класс с шеф-поваром или ресторанный формат (шеф готовит сам); продолжительность 4 часа (2,5–3 часа на приготовление); минимум 8 человек; акция — скидка 3 % на меню в день рождения и при заказе ведущих/развлечений; стоимость «от 3 300 ₽/чел». Свидание: гастрономический ужин из трёх блюд с мастер-классом, аренда студии 3 часа, шоу с огнём или жидким азотом, «от 18 000 ₽».
- **CTA:** «Связаться сейчас» (3 раза) → `/contact/`.
- **Формы:** только общий обратный звонок.
- **Изображения:** постановочные фото — шеф-повар на профессиональной кухне; пара готовит вместе. Тёплый свет, но цветокоррекция не единая.
- **Замечания:** всего 2 формата из 4+; нет ссылок на страницы «Корпоратив», «День рождения», «Романтический ужин»; вся фактура (длительность, минимум гостей, цена) свёрстана в `<h6>`-списки с галочками — семантически это подзаголовки, а не список; цена выделена красным внутри текста; нет программы, меню, фото пространства, ответов на вопросы.

### 3.3 Для детей — `/dlya-detey/`

- **Назначение:** продажа детских праздников.
- **Секции:** 1) H1 «Детский праздник в Кулинарной студии ТИ-БОН» + CTA; 2) «ДЛЯ ДЕТЕЙ» (факты + фото); 3) блок обратного звонка.
- **Контент:** формат — детский праздник; включено 2,5 часа (1,5–2 часа на приготовление); минимум 8 детей; стоимость «от 2 200 ₽/ребёнок».
- **CTA:** «Записаться сейчас» (2 раза) → `/contact/`.
- **Формы:** общий обратный звонок.
- **Изображения:** дети с выпечкой/печеньем (праздничная сервировка).
- **Замечания:** нет возрастных групп, программы, детского меню, информации о безопасности и сопровождении родителей, аллергиях, фото зоны проведения; нет ссылки на «Правила студии», где как раз указано, что за детей отвечают родители и что гости старше 5 лет оплачивают полную стоимость. Страница — один экран текста.

### 3.4 Аренда студии — `/arenda/`

- **Назначение:** сдача пространства под съёмки, мастер-классы, мероприятия.
- **Секции:** 1) H1 «Аренда студии» + CTA; 2) «Для чего можно забронировать нашу студию» — 3 карточки; 3) «Сколько стоит аренда в ТИ-БОН?» — 2 тарифа; 4) блок обратного звонка.
- **Контент:** карточки «Для фотосессий» (интерьер, мягкий свет), «Для мастер-классов» (оборудование, авторский формат), «Для мероприятий» (профкухня, приватность); тарифы «Будние дни — 3 000 ₽/час», «Вечер и выходные — 6 000 ₽/час».
- **CTA:** «Связаться сейчас» (hero), «Связаться» (в каждой карточке) → `/contact/`.
- **Формы:** общий обратный звонок; отдельной заявки на аренду нет.
- **Изображения:** человек ест десерт в кафе; еда в дыму; компания друзей в ресторане. Стоковые, разностильные.
- **Замечания:** нет площади, вместимости, перечня оборудования (печи, станции, свет, посуда), зон, парковки, правил аренды, минимального времени; тарифы без условий (что входит, есть ли минимальный заказ, кухня/уборка); нет календаря занятости и нет формы «дата + время + количество часов». Пользователь не может оценить пригодность студии под свою задачу.

### 3.5 Меню — `/menu/`

- **Назначение:** выдача меню в PDF.
- **Секции:** 1) H1 «Меню Кулинарной студии ТИ-БОН» + вводный текст; 2) форма-гейт с двумя кнопками скачивания.
- **Контент:** «В данном разделе Вы найдете меню на любой вкус, для взрослых и детей…»; «Введите ваше имя и номер телефона, чтобы скачать меню».
- **CTA:** «Скачать взрослое меню», «Скачать детское меню» (ссылки на PDF `/wp-content/uploads/2025/11/Меню_взрослое.pdf` и `Меню_детское.pdf`).
- **Формы:** Имя\*, Номер телефона\* — единственная цель: разблокировать PDF. Согласия на обработку данных нет, пояснения цели сбора нет.
- **Изображения:** нет.
- **Замечания:** меню на сайте отсутствует — ни блюд, ни состава, ни цен, ни аллергенов; телефон требуется до просмотра контента (высокий барьер, слабая SEO-ценность страницы); PDF не открывались, содержимое не проверено; после отправки формы нет описанного состояния успеха.

### 3.6 Дополнительные услуги — `/dop-uslugi/`

- **Назначение:** апселл к мастер-классам.
- **Секции:** 1) H1 «КАК СДЕЛАТЬ ПРАЗДНИК ЕЩЕ ЛУЧШЕ?» + подзаголовок; 2) блок «Весело. Оригинально. Со вкусом.» (текст о студии + CTA); 3) 5 карточек услуг с фото; 4) блок обратного звонка.
- **Контент:** «работаем с 2015 года», «90 % клиентов возвращаются», «полный цикл организации»; поводы: детские ДР 1–18 лет, выпускные, авторские квесты, тематические вечеринки, корпоративы и тимбилдинги. Карточки: ведущий Александр Подкин (проверенный ведущий, без цены), «Игра мафия / Бункер» от 3 500 ₽/час, «Квизы» от 10 000 ₽/час, «Фотограф» от 4 000 ₽/час, «Детские аниматоры» — «Цена по запросу».
- **CTA:** «Связаться сейчас» ×6 → `/contact/`.
- **Формы:** общий обратный звонок; выбора конкретной услуги в заявке нет.
- **Изображения:** портрет ведущего, настольная игра, квиз-реквизит, фотограф в работе, аниматор с шарами (последнее — явно стоковое фото на фиолетовом фоне).
- **Замечания:** шесть одинаковых CTA ведут на одну страницу — невозможно понять, какую услугу выбрал пользователь; нет состава услуги, длительности, зоны выезда, условий; «цена по запросу» без формы запроса; блок-манифест с эмодзи и «⭐» выбивается из визуального языка; часть изображений — сток, не связанный со студией.

### 3.7 Контакты — `/contact/`

- **Назначение:** связь и адрес.
- **Секции:** 1) H1 «Контакты» + подзаголовок; 2) телефон и ссылка на VK; 3) «ПРИХОДИТЕ В ГОСТИ / Ежедневно с 10:00 до 23:00 по записи»; 4) адрес; 5) блок обратного звонка.
- **Контент:** телефон «57-69-90» (в `tel:`-ссылке — `tel:566990`, расхождение с отображаемым номером); ссылка «Ти-Бон» на VK; адрес: Удмуртская Республика, Завьяловский район, село Первомайский, улица Архитектора Сергея Макарова, 2/4, офис 3.
- **CTA:** номер телефона, «Ти-Бон» (VK), «Перезвоните мне».
- **Формы:** обратный звонок (имя, телефон).
- **Изображения:** нет.
- **Замечания:** нет карты, схемы проезда, ориентиров, парковки, фото входа; нет email и мессенджеров (Telegram/WhatsApp), хотя аккаунты есть в шапке; часы работы на странице (10:00–23:00) противоречат JSON-LD на главной (`Mo–Su 09:00–17:00`); клик по телефону с мобильного приведёт на неверный номер из-за `tel:566990`.

### 3.8 Правила студии — `/pravila/`

- **Назначение:** регламент визита и отмены.
- **Секции:** 1) H1 «Правила нашей студии» + вступление; 2) список правил; 3) «Правила отмены и изменения бронирования».
- **Контент:** администрация не отвечает за личные вещи; за детей отвечают родители; все гости старше 5 лет участвуют в мастер-классе и оплачивают полную стоимость; приносить еду, напитки, фрукты и торты запрещено; курение запрещено; разбитая посуда оплачивается по стоимости предмета. Бронирование: предоплата 50 %; отмена за 10 дней — полный возврат; за 5 дней — перенос даты; при отмене перенесённого мероприятия возврат не предусмотрен; изменение количества гостей — не позднее 2 дней до события.
- **CTA:** нет.
- **Формы:** нет.
- **Изображения:** нет.
- **Замечания:** юридически значимый текст без даты редакции и без ссылки на оферту/пользовательское соглашение; нет якорной навигации; пункт про оплату гостей 5+ и запрет своей еды — критичная информация, но она не показывается в момент выбора формата и не дублируется на страницах услуг; страница спрятана в подменю «О нас».

### 3.9 Корпоратив — `/korporativ/` (сирота)

- **Назначение:** SEO-лендинг под запрос «корпоратив».
- **Секции:** 1) H1 + CTA; 2) «ПОСМОТРИТЕ ФОТО С НАШИХ МЕРОПРИЯТИЙ» (2 фото); 3) «КОРПОРАТИВ» (факты + фото); 4) блок обратного звонка.
- **Контент:** 4 часа (2,5–3 часа приготовление), минимум 8 человек, скидка 3 % при заказе ведущего/развлечений, «от 3 300 ₽/чел».
- **CTA:** «Записаться сейчас» ×2 → `/contact/`.
- **Изображения:** фото с мероприятий (2 шт., без подписей и alt).
- **Замечания:** дублирует блок со страницы «Для взрослых»; нет ссылки из навигации и из родительской страницы; нет программы, меню, командообразующих сценариев, кейсов, логотипов клиентов.

- **Изображения:** 2 фото (одно — `XXL_height.webp`, вероятно сток).
- **Замечания:** подзаголовок «Взгляните на атмосферу наших свиданий» скопирован со страницы свиданий — контентная ошибка; формула расчёта без примера и без цен меню.

### 3.11 Романтический ужин — `/romanticheskiy-uzhin/` (сирота)

- **Контент:** три блюда с мастер-классом, аренда 3 часа, шоу с огнём или жидким азотом, «от 18 000 ₽».

- **Контент:** 15 `<img>`, но уникальных файлов 5 — одна и та же пятёрка повторена трижды.
- **CTA:** нет.
- **Изображения:** фото мероприятий/диплом (`diploma.webp`), без alt, без подписей, без категорий.
- **Замечания:** дубли, нет лайтбокса (не проверено), нет фильтров, нет связи с форматами; страница недоступна из меню.

### 3.13 «Просто праздник» — `/prazdnik/` (сирота)

- **Статус:** страница существует и возвращает 200, но **контент отсутствует** — считать незаполненной, не выдумывать содержимое.

### 3.14 «О нас» — `/about/` (сирота)

- **Назначение:** рассказ о студии.
- **Контент:** англоязычный шаблон-заглушка: «About», «Subheading: Craft a compelling subheading that sparks curiosity.», «About Heading», «About Text: In this section, you can provide a detailed paragraph…», две кнопки «CTA Button» с `href="#"`, картинка `square-1.png`.
- **Статус:** технически доступна, содержательно **не готова**. Фактов о студии (команда, шеф, история, пространство) на сайте нет ни на одной странице, кроме фразы «работаем с 2015 года» на `/dop-uslugi/`.

**Обязательное правило домена (фиксируется в спецификации и API):**
отправленная заявка **не является подтверждением бронирования**. Заявка создаётся в статусе `new`, не блокирует дату и не гарантирует место. Подтверждение — только действие администратора (`new → contacted → confirmed | declined`). Это должно быть явно написано в интерфейсе: и рядом с кнопкой отправки, и в экране успеха. Уведомление клиенту об успешной отправке не должно содержать слов «вы забронировали».

Backend требуется для: заявок (хранение, статусы, модерация), контента (услуги, меню, галерея, тексты, контакты), медиа, SEO-полей, уведомлений (email/Telegram), антиспама и аудита изменений.

## 5. Пользовательские сценарии

Ниже — реальные пути по референсу и места, где путь рвётся.

**S1. Родитель ищет детский день рождения.**
Поиск/реклама → главная (постер без оффера и ссылок) → меню «Для детей» → один экран с ценой «от 2 200 ₽/ребёнок» → «Записаться сейчас» → `/contact/` с общей формой звонка.
Разрывы: нельзя указать возраст ребёнка, количество детей, дату, аллергии; нет программы и фото; нет ответа, остаются ли родители; нет ссылки на правила; после отправки — только «мы перезвоним».

**S2. Секретарь/HR ищет корпоратив на 15 человек.**
Главная → «Для взрослых» → блок «Мероприятия для взрослых» (минимум 8 человек, 4 часа, от 3 300 ₽/чел) → «Связаться сейчас» → `/contact/`.
Разрывы: страница «Корпоратив» не доступна из навигации; нет вместимости, парковки, меню, счёта для юрлица, программы тимбилдинга.

**S3. Пара ищет необычное свидание.**
Поиск «свидание мастер-класс» → `/romanticheskiy-uzhin/` (сирота, но индексируется) → «от 18 000 ₽» → «Записаться сейчас» → `/contact/`.
Разрывы: нет состава ужина, выбора блюд, опций (цветы, музыка), нет фото пространства; цена без объяснения, что входит.

**S4. Фотограф ищет локацию под съёмку.**
Поиск «студия для фотосессии» → `/arenda/` → карточка «Для фотосессий» → «Связаться» → `/contact/`.
Разрывы: нет площади, высоты потолков, естественного света, розеток, фонов, времени загрузки, парковки, правил и стоимости минимальной брони; нет календаря занятости; заявка не фиксирует дату.

**S5. Гость хочет посмотреть меню перед записью.**
`/menu/` → форма «имя + телефон» → PDF.
Разрывы: барьер до контента; на сайте нет ни одного блюда; нельзя сравнить взрослое и детское меню; PDF неудобен на телефоне; нет цен и аллергенов.

**S6. Организатор хочет добавить фотографа и квиз.**
`/dop-uslugi/` → карточки услуг → «Связаться сейчас» (одна и та же кнопка) → `/contact/`.
Разрывы: невозможно сообщить, какая услуга нужна, кроме как текстом; нет длительности, состава, условий выезда; «цена по запросу» без формы запроса.

**S7. Клиент проверяет условия отмены до оплаты.**
Главная → «О нас» (пункт без ссылки, только раскрывает подменю) → «Правила студии» → текст.
Разрывы: пункт «О нас» не кликабелен и не ведёт на страницу; правила не видны на страницах услуг; нет даты редакции.

**S8. Пользователь со смартфона хочет позвонить.**
Шапка → телефон «57-69-90» → `tel:566990` → звонок на неверный номер.
Разрыв: расхождение отображаемого номера и `tel:`-ссылки.

**S9. Пользователь ищет адрес и маршрут.**
`/contact/` → адрес текстом → копирование в карты вручную.
Разрывы: нет карты, ссылки «Построить маршрут», ориентиров, фото входа.

## 7. Требования к адаптивности

Брейкпоинты: **360 / 480 / 768 / 1024 / 1280 / 1440+**. Подход mobile-first, контейнер до 1280 px, боковые поля 16 px (мобайл) / 24 px (планшет) / 40 px (десктоп).

- **Навигация.** До 1024 px — кнопка-бургер, полноэкранное меню-sheet: фокус-трап, закрытие по Esc и клику по оверлею, возврат фокуса на триггер, блокировка скролла body. Телефон и кнопка «Оставить заявку» доступны в меню.
- **Sticky-действия.** На мобайле — нижняя панель с двумя действиями: «Позвонить» и «Оставить заявку». Не перекрывает контент (safe-area inset), скрывается при открытой клавиатуре.
- **Тач-таргеты** ≥ 44×44 px, расстояние между соседними ≥ 8 px.
- **Типографика.** H1: 40 px → 64–80 px на десктопе (fluid `clamp`); body 16–18 px; минимальный кегль 14 px только для подписей.
- **Формы.** Одна колонка, поля на всю ширину, `font-size` ≥ 16 px (иначе iOS зумит), `inputmode` для телефона, видимые label (не placeholder вместо label), ошибки под полем.
- **Изображения.** `srcset`/`sizes`, AVIF/WebP с JPEG-фолбэком, `loading="lazy"` кроме первого экрана, фиксированные `aspect-ratio` (без layout shift). Hero на мобайле — не выше `100svh` и не тяжелее ~250 КБ.
- **Галерея.** 2 колонки на мобайле, 3 на планшете, 4 на десктопе; лайтбокс — свайп, стрелки, Esc, фокус-трап.
- **Таблицы/тарифы.** На мобайле — вертикальные карточки, не горизонтальный скролл.
- **Движение.** Анимации 150–300 мс, только `transform`/`opacity`; при `prefers-reduced-motion: reduce` — отключены.
- **Проверка.** Отдельно проверить 360×640, 390×844, 768×1024, 1024×768, 1440×900; горизонтальный скролл запрещён на всех ширинах.

**Ограничение:** адаптивность референса визуально не проверялась (нет браузера); требования выше — нормативные для нового сайта, а не описание того, как это сделано на ti-bon.ru.
