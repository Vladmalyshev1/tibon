# Frontend Quality Skill

Before implementation:
1. Read AGENTS.md.
2. Inspect existing components.
3. Check design tokens.
4. Check API contracts.

Implementation:
- Use reusable React components.
- Use strict TypeScript.
- Avoid any.
- Keep components focused.
- Use semantic HTML.
- Implement keyboard accessibility.
- Support responsive layouts.
- Optimize images.
- Handle loading and error states.
- Avoid unnecessary animations.

Verification:
- Run lint.
- Run TypeScript checks.
- Run Vitest.
- Run production build.
- Use Playwright when available.
- Inspect mobile and desktop screenshots.

Never replace a real API with mock responses in production.
