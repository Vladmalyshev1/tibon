# Reference Audit Skill

When analyzing a reference website:

1. Inspect every requested page.
2. Identify shared and unique sections.
3. Inspect desktop and mobile layouts.
4. Inspect navigation and interactive elements.
5. Identify forms and their behavior.
6. Capture screenshots when browser tools are available.
7. Document page structure.
8. Identify missing assets and business information.
9. Separate observed facts from assumptions.

Output:
- Page inventory.
- Component inventory.
- User flow documentation.
- Visual observations.
- Unresolved questions.

Never claim a page was inspected if it was inaccessible.
