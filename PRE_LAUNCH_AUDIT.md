# TIBON — аудит перед публикацией

**24 ноября 2026 г. · Вердикт: публичный запуск с открытыми формами пока не готов.** Локальная production-сборка, API и сквозные сценарии работают. До запуска нужны утверждённые правовые документы, проверка настроек домена и релизный тест за фактическим шлюзом. Мобильный Lighthouse Performance ниже цели на 9 из 10 индексируемых страниц.

Проверено текущее рабочее дерево, включая существующие незакоммиченные файлы. SSR запускался на loopback с тестовым origin `https://tibon.example` и отдельно без origin. В тестах API использованы браузерные моки и отдельный PostgreSQL с синтетическими данными и PDF. Сквозной тест выполнен через временный same-origin шлюз на Node.js. Production, его фактическая индексация и кабинеты не проверялись. Рабочие PDF не открывались. Реальные заявки и Telegram-сообщения не отправлялись.

Для точных дублей задать 301/308 на выбранный URL с сохранением query. `/menu/?type=kids` меняет основной вариант скачивания, canonical остаётся `/menu/`. С origin robots отдаёт 200, `Allow: /` и абсолютный sitemap. Все 10 URL из XML проверены отдельно. Для 14 внутренних URL со статусом 200 и обнаруженных якорей битых целей нет. Браузером открыты 46 внутренних CTA. [Каноникализация Google](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) · [Правила robots meta](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag)
- **SSR.** Сырой HTML содержит навигацию, H1, основные тексты, CTA, контакты, опубликованные цены и условия. В Chromium без JS подтверждено на главной, страницах взрослых, детей, меню, контактов и заявки. Формы отключены до гидратации. На главной и заявке есть подсказка позвонить. В меню без JS есть подсказка включить JavaScript, скачивание через форму недоступно.
- **Изображения, OG и иконки.** Все 57 элементов `img` в проверенных ответах имеют alt. Пустой alt только у декоративной иконки MAX с видимой подписью. На мобильном изображения декодировались. OG-файл главной локально вернул 200, у остальных девяти URL отсутствует `og:image`. Подготовить утверждённые широкие превью с абсолютными URL и `og:image:alt`. В HTML нет favicon, `/favicon.ico`, `/apple-touch-icon.png` и `/manifest.webmanifest` возвращают 404. [Google о favicon](https://developers.google.com/search/docs/appearance/favicon-in-search)
- **LocalBusiness.** JSON-LD отсутствует. Добавить сущность на главную или контакты и единый `@id`. Использовать подтверждённые бренд, полный телефон, канонический URL, фактический адрес в с. Первомайском, часы с оговоркой «по записи», реальные фото и профили в `sameAs`. Перед `geo` сверить метку с входом. Опубликованные сведения об ИП сверить с владельцем. Не добавлять неподтверждённые контакты, отзывы, рейтинг и сведения об организации. [Google о LocalBusiness](https://developers.google.com/search/docs/appearance/structured-data/local-business)
